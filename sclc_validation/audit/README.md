# SCLC validation audit

This directory contains the reproducible feasibility audit supporting
`SCLC_DATA_FEASIBILITY_AUDIT.md`.

- `audit_sclc_data.py`: source-integrity, cohort, marker, and compatibility checks
- `notebooks/SCLC_data_feasibility_audit.ipynb`: executable reader-facing audit
- `results/`: compact, repository-trackable evidence tables
- `source_metadata/`: ignored local copies of open-access source files

The audit does not modify the existing NSCLC pipeline.
